# Project Summary

## Application: Meme Factory

* A dynamic React-based meme generator that brings your memes to life with animated text effects. <br>

## Features

* **Random Meme Generation**: Generate fresh meme templates with a single click
* **Dynamic Text Animation**: Watch your text appear symbol by symbol as you type
* **Dual Text Positioning**: Add custom text to both top and bottom of your memes
* **Text Persistence**: Your text stays across different meme templates until explicitly changed or deleted
* **Real-time Preview**: See your meme come to life as you type

## Getting Started
### Prerequisites

* Node.js (v14.0.0 or higher)
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/evokss/MemeFactory.git

# Navigate to project directory
cd meme-factory

# Install dependencies
npm install

# Start the development server
npm run dev`
```
